# 👨‍💻 MyProfile – Personal Portfolio Website

**Developed by Ankit Pandey**

A modern, responsive, and professional personal portfolio website built using HTML, CSS, Bootstrap, and JavaScript. This project showcases my profile, technical skills, projects, and career goals as an aspiring .NET Full Stack Developer.

## 🌟 Features

- 🏠 **Home Section** – Introduction and professional overview.
- 👨‍💻 **About Me** – Personal introduction and career objectives.
- 🛠️ **Skills Section** – Highlights technical skills and technologies.
- 📂 **Projects Section** – Displays personal and development projects.
- 📄 **Resume Download** – Allows visitors to download my resume.
- 📱 **Responsive Design** – Compatible with desktop, tablet, and mobile devices.
- 🎨 **Modern UI** – Clean layout with an attractive design.
- 🔗 **Social Media Links** – Connect through social media and professional platforms.
- ✨ **JavaScript Interactions** – Dynamic elements and enhanced user experience.

## 🛠️ Technologies Used

- **HTML5** – Website structure
- **CSS3** – Styling and layout
- **Bootstrap 5** – Responsive design and UI components
- **JavaScript** – Interactive functionality
- **Bootstrap Icons** – Social media and interface icons

## 📸 Project Overview

The MyProfile website is designed to present my technical skills, projects, and professional information in one place. It serves as an online portfolio for showcasing my frontend development skills and my journey toward becoming a .NET Full Stack Developer.

## 🚀 How to Run the Project

1. Clone the repository:

   ```bash
   git clone https://github.com/Ankitpandeyup51/MyProfile.git
   ```

2. Open the project folder:

   ```bash
   cd MyProfile
   ```

3. Open the `index.html` file in your browser.

4. Alternatively, open the project in Visual Studio Code and run it using the Live Server extension.
